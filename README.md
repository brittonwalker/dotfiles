# Britton's Development Environment

## Philosophy

- Keep the shell minimal.
- One responsibility per file.
- Prefer native tooling over frameworks.
- Symlink configs rather than copy them.
- Every installed tool should have a purpose.

## Bootstrap

brew bundle
./install.sh
